### 0.3 已确认的保真边界

GT6 固定来源里，热锭是 **身份 + 静态伤害**，不是一条冷却配方：

| 行为 | GT6 | 本卡处置 |
|---|---|---|
| `OP.ingotHot` 存在 | 是 | 保留 CC `ingot_hot` |
| `ingotHot.mHeatDamage = 3.0F` | 是 | 保留 prefix heat damage |
| 材料额外 `mHeatDamage` | 有则叠加 | 保留 `MaterialContactHeat` |
| 物品 tick 把热锭换成普通锭 | **无** | **删除** CC 自动换物 |
| `gt.recipe.freezer` 通用冷却 | **无**；freezer 是材料变换 | 保持 `post_1_0`，不借用 |
| 温度组件随时间降到环境 | CC 自己的 runtime 快照 | 可保留温度衰减，但 **不得改物品 id** |
| 创造栏 / 指令热锭缺 HEAT 组件 | CC 维护层补熔点 | 保留 `HotIngotProcessing.initializeIfMissing` |

因此 T27 拓扑里那句

> replace `hot_ingot_to_ingot.json` DESIGN_POLICY

在本卡被解释为：**用 source-backed「无转换」替换这条未验证规则，而不是另找一条 GT6 冷却配方填进去。**
不得把 freezer、水槽、通用冷却机或新 RecipeMap 当作 GT6 等价物。
