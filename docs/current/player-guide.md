# CrucibleCraft 玩家指南（0.1.0-test.20260922.1）

> **小群私测快照，不是公开测试、不是 RC、不是 GA、也不是 `1.0.0`。**
> 不要发到 CurseForge / Modrinth / GitHub Release。旧档不要拿来升级。
> 模组列表里应显示 `0.1.0-test.20260922.1`。

## 0. 先读这几条

- **新开世界。** 公共 16 材料前缀已改成独立 Item，铸造坩埚/砧/大坩埚也在改 hosted 身份；没有 DataFixer。`0.1.0-beta.1` / `0.1.0-rc.1` 存档会丢物品或对不上方块。
- **机制能跑 ≠ 生存全通。** 不少配方、形态、获得路径仍 blocked。卡配方时不要用创造凑「看起来像」的替代品当正式流程，记下来反馈即可。
- **第一次进世界可能卡住几分钟。** 等加载结束，不要当死机强关。建议 ≥16 GiB 内存。
- **客户端和服务端必须是同一份 jar。** 材质定义不一致会在进服时被拒绝。

## 1. 安装

1. 安装 Minecraft 1.21.1 与 **NeoForge 21.1.243 或更高**（Java 21）；
2. 把 `cruciblecraft-0.1.0-test.20260922.1.jar` 放入 `.minecraft/mods/`；
3. （可选）EMI `1.1.24+` 查看配方、Jade `15+` 查看方块信息；再加 Reliable EMI（REMI / EMI++）`4.7.3+` 可把同形态材料（粉、锭、碎矿、工具头等）、同种工具、同种加工机 / 能量转换器，以及玻璃 / 木板 / 台阶等建筑方块、书架、抽屉、保险箱、箱子、料斗、坩埚、模具在物品列表里折叠。YACL 是 REMI 的依赖。缺 EMI / Jade / REMI / KubeJS 仍可启动；
4. 启动游戏，确认模组列表中出现 CrucibleCraft `0.1.0-test.20260922.1`。

**多人**：服务端安装同一 jar。Handshake `NETWORK_VERSION` 仍为 `"1"`。

## 2. 建议首玩路径（五节点）

下面是建议走的主链，用来感受矿→热/蒸汽→油汽→管网→多方块。  
**不保证**每一步都能在纯生存、零创造下走完；缺件或配方对不上就记下 id 反馈。

### 节点 1 · 获取并处理世界资源

- 在主世界找石层矿和散点小矿（`gt_small_ore`）。默认 GENERATE_STONE 关掉主世界大矿脉；下界同样散点小矿。Coltan 在主世界有一块热点。
- 原油与天然气是地下流体矿藏，用管道 + 泵提取；
- 主世界基岩底还会按 GT6 `WorldgenFluidSpring` 出超重油/重油/中油/轻油/天然气/地热水/熔岩泉（与基岩矿互斥，一 chunk 一口泉）。桶取的是对应世界流体，不是 `crude_oil`。超重/重/中/轻油都可直接进蒸馏机（各自身份 → 燃油+润滑油）；T9 `crude_oil` 仍走 dump 872 的同一组量。四油/气/地热是 16 格有限流体（muffin meta 15；泉砖往上补 `+8` 或空位放 meta 7）；桶取走 8 格（1000 mB），满 muffin 会留下 meta 7。浸在油里会中毒/反胃（没顶在液面下才喘到）并致盲，超重/重油还会像蜘蛛网一样粘人，地热水给再生和抗性，天然气只喘不到药浴；非地热体会每秒淹死 1 心。熔岩仍是原版无限源。
- 用研钵/粉碎/筛分链把矿石处理成粉末，进坩埚熔炼。本快照里坩埚、模具、砧按 GT6 hosted 材料方块放，不再是单一 `crucible` 方块。
- 原版纸已改成 GT6 口径：3 甘蔗合成 **1** 张纸（不再是原版 3→3）。
- 原版熔炉是 8 圆石（或石头石子）加点火物：打火石、火焰弹、火柴或燧石引火。
- 骨粉要锤子敲骨头，只出 1 份。铁/金板件（桶、铁门、漏斗等）、红石机构到命名牌、矿车（铁板+轮）和锁链甲（钢环）已按 GT6 工作台替换。TNT 仍可用沙子，也可用火药粉+二氧化硅粉。曲奇 / 金苹果 / 金胡萝卜工作台已删。

### 节点 2 · 从热力/蒸汽进入能源与机器阶梯

- GT6 Burning Box 分档已进游戏。热力加工用燃气燃烧室出 HU（只烧气体：天然气可直接烧，也可
  generifier 成甲烷），液体燃烧室烧柴油/煤油/汽油/原油/泉油等液体燃料；气/液箱都要正面打火石
  点火，着火后会往周围蔓延。固体燃烧室可用煤 / 焦炭宝石出 HU。流化床燃烧室吃粉尘（含 1/72 粉
  和粉块）+ 熔融方解石：方解石粉进冶炼炉出 144 mB，每份粉尘配方 72 mB；流体单元可灌装熔融方解石
  （其它熔融金属仍不能进单元），正面打火石点火。焦炉是 3×3×3 耐火砖空心（主方块在侧面正中朝外），
  不需要下方火箱：打火石点火后靠环境 TU 运行，一次最多 16 份；杂酚油会滴到炉底正下方 3×3 的储罐。
  耐火砖顶面可漏斗进料、底面抽出，砖上也能点火/开界面；相邻焦炉不能共用同一块砖。
  焦炉除煤外还收原版原木（橡木等 250 mB 杂酚油；苍白橡木/红树木/樱花/下界菌柄 200 mB）、GT 树原木（橡胶/枫/柳等）、褐煤、油页岩（出原油+沥青粉），以及煤/褐煤粒和细碎矿。
- 锅炉（80 HU + 1 mB 水 → 160 mB 蒸汽；蒸汽过半罐才从顶面喷出，过热或满汽会炸）→ 蒸汽机（200 mB 蒸汽 → 50 KU，
  青铜额定 12 KU、随库存 6–24 KU/t）驱动 KU 机器（压机等）仍可用，但需要上述 HU 源；
- 中期：燃油引擎（1 单位燃油 → 512 RU）经轴/齿轮箱 → 发电机
  （32 RU → 22 EU + 10 损耗）→ 电缆（逐块精确损耗）驱动 EU 机器
  （电解机等）。电加热器把 EU 转 HU，电引擎把 EU 转 KU。热电冷却器把 EU 转成前面 CU、后面 HU；
  热通量冷却器同样出 CU/HU，输入是 FE（GT6 RF 按数量 1:1）。螺丝刀只调电力冷却器的 0–15 档。
- 后期内容在工作树里能看到，**不是本快照的完成承诺**：LU 光纤只传 LU。裂变堆芯 / 棒 /
  LV Canner 已能跑。大型热交换器已按 GT6 结构运行，生存获得还没审。蒸汽涡轮与聚变的代码在，卡仍暂停。它们都不是生存终局。

### 节点 3 · 三种下游产品

- 蒸馏机处理原油或超重/重/中/轻油泉 → 燃油 + 润滑油；统一器可把超重/重/中/轻油收成 `oil`；燃油/柴油/煤油/汽油等进燃油引擎或液体燃烧室，不要灌进燃气燃烧室；
- 天然气可直接进燃气燃烧室，也可 → 甲烷 → `bronze_burning_box_gas`（甲烷 1,536 单位 → 1,152 HU + 9 mB 废气）；
- 以任意一种下游产品完成一个「开采→加工→供能」闭环即达标。

### 节点 4 · 至少一个自动化循环

- 例：泵 cover 从流体矿藏抽油 → 管道 → 蒸馏机 → 燃油管道 →
  引擎 → 发电 → 机器加工，全程无人工搬运。

### 节点 5 · 形成并运行一座多方块

- 蒸馏塔 / 大型锅炉 / 3×3×3 储罐任选一座；
- 按结构摆放控制器与 port（错放会给出诊断且不破坏已放方块）；
- 大型锅炉使用不锈钢、殷钢、钛、钨钢或艾德曼五档
  `boiler_main_barometer` 控制器；底层致密墙进水，上层致密墙出汽，
  仅蒸馏水不会结垢，满汽/过热/高压拆机有爆炸风险，凿子可除垢、活塞可排空；
- 运行并确认产物/流体正常进出 port。

## 3. 旧存档

- 旧的 `cruciblecraft:large_boiler` 控制器只走一次兼容迁移，会替换为不锈钢
  `boiler_main_barometer` 并保留水、蒸汽、HU 和结垢状态；原通用结构不会自动补墙，
  需要按五档结构重摆。
- **不要加载** `0.1.0-beta.1`、`0.1.0-rc.1` 或开发期世界。本快照未做旧物品/坩埚方块迁移。
- 本模组从未公开发布过 0.1 之前的版本，**不承诺任何外部旧档的兼容**。
- 发现坏档：复制世界再试，不要拿唯一存档做升级试验。

## 5. 本快照范围

工作树已经超过历史上的 `0.1.0-rc.1` 冻结（电转换、LU、裂变、电池芯、连接件 / MTE runtime、仓储贴图、混合材料身份、铸造 hosted 改动）。私测看到的就是当前工作树，**不是**那份 RC 合同。

- 支持：1.21.1 + NeoForge ≥ 21.1.243 + Java 21；单机与 dedicated server；
- 可选依赖：缺 EMI / Jade / REMI / KubeJS 可启动；存在时客户端加载 EMI / Jade；有 REMI 时按材料前缀、工具种类、加工机 / 转换器 kind，以及玻璃 / 木板 / 台阶等建筑方块、书架、抽屉、保险箱、箱子、料斗、坩埚、模具折叠物品列表；
- 不支持：对外公开分发、旧档升级、GT6 全量配方、G10 / GT6U；
- 大型热交换器 / 蒸汽涡轮 / 聚变不当成可玩终局；
- 反馈：小群里直接说，或 https://github.com/icodestuljh/cruciblecraft/issues（附上 **`0.1.0-test.20260922.1`** + 复现步骤 + 日志 / 崩溃报告）。
