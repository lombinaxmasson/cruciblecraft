## 0. 开场判断

GT6 大型燃气轮机是 HU 电容 + FM.Gas 燃料并行消耗 + RU 从背面远墙射出。
墙是 18022/18026/18023/18025 致密不锈钢/钛/钨钢/艾德曼壁，与大型蒸汽轮机同一套。
合成 `PwP / BMC / PEP`：M 是对应蒸汽轮机主机壳 17211–17214，B 是 `gt:re-battery1–4` 的 OD 首注册铅酸电池，C 是 `OD_CIRCUITS[6]`，E 是 `IL.MOTORS[1–4]`，P 是致密板，w 是扳手。缺 live 形态就跳过该行。
