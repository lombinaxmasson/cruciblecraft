## 0. 决策

切片机、印刷机、注射机、织机卡的是同一组 GT6 中间件数组，不是各自主机的私有零件。
本卡建立全档位账本，并按源网格落地所有 0–5 档技术对象。

GT6 里 `IL.CONVEYERS / PUMPS / ROBOT_ARMS` 就是盖板物品。本卡收回：

- `IL.CONVEYERS[n]` → `compact_electric_conveyor_*`
- `IL.PUMPS[n]` → `compact_electric_pump_*`
- `IL.ROBOT_ARMS[n]` → `compact_electric_robot_arm_*`

已有 `compact_electric_motor_lv/ev` 与 `compact_electric_piston_ev` 复用。
`wireGt03/05/06` 使用真实的 `triple_wire/quintuple_wire/sextuple_wire` 前缀。
LuV–PUV1 盖板升级链仍是历史 `programmed_circuit` 配方，不在本卡 0–5 分母内。

## 1. 分母

来源：`MultiItemTechnological.java` 49–56、405–456。
档位 `MT.DATA.Electric_T[0..5]`：TinAlloy / SteelGalvanized / Al / StainlessSteel / Cr / Ti。

配方网格：

- 传送带 `"RRR","MCM","RRR"`：橡胶板 + 同档电机 + `CABLES_01[档]`
- 活塞 `"TPP","dSS","TMG"`：同档板/杆/小齿轮/螺丝 + 电机 + 螺丝刀
- 泵 `"TXO","dPw","OMT"`：同档转子/螺丝/弯板 + 橡胶环 + 同档电机
- 机械臂 `"CCC","MSM","PES"`：同档电缆 + 电机 + 活塞 + 杆 + 同档电路
- 力场发生器 `"WPW","CGC","WPW"`：锇线规 + 双板 + 同档电路 + 珍珠/末影之眼/下界之星
