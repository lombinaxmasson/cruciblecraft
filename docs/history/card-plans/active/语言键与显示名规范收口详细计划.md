## 0. 决策

当前语言合同是分裂的，不是观感问题。Minecraft 运行时用
`Util.makeDescriptionId` 把 registry path 里的 `/` 换成 `.`。datagen 给管道 /
电缆 / 材料方块写的是斜杠键，catalog identity 写点号键，gate 按点号查，
`MaterialVisualResourceTest` 按斜杠断言。斜杠键在世界里和 Jade 上可以是死键。

英文 `title()` 只把整串首字母大写，所以 `fluid_pipe` 变成 `Fluid pipe`。
`zh_cn` 里有 `Water Twig`、`Asphalt Black`、`Flower Black dye` 这类英文复制。
那不是合法 fallback。合法 fallback 是不写 zh 键，让客户端回退 `en_us`。

`Water Twig` / `Lava Twig` 是 GT6 source-backed 名称（材料 + `plant_gt_twig`）。
确认材料名与前缀后，英文保持这个词序；中文要么给真翻译，要么省略键。
不得按自然语言直觉改成别的英文身份。

本卡不解决任何机器、配方、获得格或 blocked 内容。晋升落地之前不得把手改
`src/generated/resources/assets/cruciblecraft/lang/**` 当成实现。

## 1. 分母

两条生成通道必须共用同一套键和值：

1. datagen `ModLanguageProvider` → `src/generated/resources/.../lang/`
2. 运行时材质包 `GeneratedMaterialPack.planClientFiles`

对象类型：`block` / `item` / `fluid` / `fluid_type`。模板键
（`item.cruciblecraft.material_form.*`、`material.cruciblecraft.*`、GUI / EMI /
Jade / config）不是 registry path，不改成 registry 规则。

`MaterialZhNames` 只读 `materials` / `prefixes` / `pipes` / `conductors`。
根级 `neutronium` / `superconductor` 现在不会被加载。`pipes` 用
`normal_fluid_pipe`，Java canonical 是 `fluid_pipe`，中号管中文因此缺失。

`generated_resource_gate` 的 live inventory 来自静态 catalog 与 `ModBlocks`
注册，漏掉动态材料块、管道和电缆。没有 display-name collision gate。

---

## 2. 实施分区

### A. 语言键 canonical contract

唯一转换：`object_type + '.' + namespace + '.' + registry_path.replace('/', '.')`。
block 与 item 共用同一 path 映射。禁止各生成器自己写一套 `replace('/', '.')`。

验收：斜杠 registry-backed 键归零；`MaterialVisualResourceTest` 迁到点号键；
`player_complete` 的双查找只作迁移期保护，关闭时删掉旧分支。

### B. 英文显示名生成器

snake_case 按词 Title Case，再走 prefix / token 例外表。
`fluid_pipe → Fluid Pipe`，`hslasteel → HSLA Steel`，
`plant_gt_twig → Twig`，因此 `water + plant_gt_twig → Water Twig`。
source-backed catalog 的 `english_name` 原样保留。

轴向写 `X` / `Y` / `Z`，不泄露 `axis x`。`m8` / `m9` 不得出现在玩家名里，
除非该 meta 本身就是正式身份；安山岩走路径上的 `reinforced_bricks`。

### C. 中文翻译与 fallback

`zh_cn` 必须是真中文。缺翻译就省略键。禁止在中英文分支都写 `englishName()`。
落地时把 `neutronium` / `superconductor` 移进 `materials`，把
`normal_fluid_pipe` / `normal_item_pipe` 改成 `fluid_pipe` / `item_pipe`。
中文材料+形态不加 ASCII 空格（`铝块`），英文保留空格（`Aluminium Block`）。
不为 post-1.0 材料凭空补中文。

### D. Display-name collision

正式身份必须可区分。同名只允许进带出处的 allowlist。书架 / 瓶箱木变体
共享 GT6 source-backed 英文，进 allowlist。沥青台阶、彩色 beam、安山岩
强化砖靠路径消歧，不进 allowlist。

### E. 生成与验证

语言文件只能由 datagen / catalog generator 生成。datagen 连续两次并比较
generated tree。扩大 gate live inventory。新增 slash-to-dot 回归与 collision
门。`generated_resource_gate`、材料/加工机资源测试、`player_complete` 与
isolated 合同测试一起 PASS。

## 3. 明确不做

- 不修改 GT6 registry path、CrucibleCraft registry ID、ResourceLocation、
  模型 / 贴图 / loot 路径或存档迁移协议。
- 不把语言键迁移伪装成 runtime 或 `player_complete`。
- 不重写 sealed R0、历史关闭计划或 post_1_0 材料分母。
- 不用统一泛名消除真实身份，不用英文值冒充中文翻译。
- 不依据 `Water Twig` / `Lava Twig` 的自然语言观感偏离 GT6 source-backed 命名。
