## 0. 决策

T48 当时只剩 unique item 能过门：1.21 没有 meta、不许 lossy alias、
本卡不新开前缀/component。材料线已经走对了（`MaterialItem`、
`material_pickaxe`）。工具头停在 identity catalog，ordinary / semantic
又按同一套复印。

| | 材料线（已对） | 现在（工具头） | 本卡 |
| --- | --- | --- | --- |
| 注册 | `材料 × 前缀` 一个物品 | `(source_item, meta)` 一个物品 | 折回 `材料 × 前缀` |
| 权威 | `MaterialCatalog` + prefix JSON | bath / semantic 两份 catalog | **一份** remap，禁止再按波次各注册一截 |
| 配方 | `MaterialRule` 可展开 | exact / 矩阵允许元组 | 默认仍 exact / 矩阵，只换 runtime id |
| 匹配 | 前缀 / tag | exact item id | 前缀物品 + 现有闭集 tag；**不**开放「任意油」 |

「折回前缀」不是把 `#0025` 写成「任意生镐头 + 任意油」。油种改出口的
family 仍是允许元组，格子从独立物品变成 `材料 × 生镐头`。

## 1. 完成后应该成立的工作流

```text
freeze remap: (source_item, exact meta) -> (material, prefix) | remainder
  authority = existing material_id_to_cc (GT6 meta → CC 材料)
  bath ∪ semantic，同一 source_item 一份表

  一种头一张 SOURCE_BACKED 贴图 + 材料 tint
  lang 走 material_form 模板，不再为 _mXXXX 写键

hard gate: 新 identity emit 不得再把 tool_head 写成 unique item
cheap siblings if clean: keys / circuit wiring / 重复挤出模具

  -> TOOL_HEAD_PREFIX_READY
       or BLOCKED
```

关键分界：

1. 语义 family 仍是 1 个 `family_id`、1 个 RecipeHolder。
2. T48 / 相关波的 **family 集合与 relation 条数** 必须与关卡前一致。
   换 id、不少行、不多行。换成开放 tag 匹配是失败。
3. `#0025` 仍是 1116 条允许元组，不是函数。
4. 只有整族被证明是「同材料、前缀变换、展开数 = lock」时，才允许
   改写成 `MaterialRule`。默认不改 representation class。
5. 没有玩家发行：不保留 7990 个旧 id 别名物品。配方 / 标签 / 创造栏
   改写即可。含旧 id 的开发存档不承诺可迁移。
6. 关闭后 `next_unassigned = true`。账本内容下一张仍是 Item Network

## 3. 权威分母

本卡不拥有新 family。分母是 **注册权威** 和 **关系集合等价**。

### 3.1 必须折回的 cohort（A）

`kind = tool_head` 且 `source_item` 为 `gregtech:gt.meta.toolHead*`
（含 `toolHeadRaw*`）的 bath + semantic 行。

映射：

```text
prefix  ← source_item 的 GT6 前缀名（toolHeadRawPickaxe → 一条新前缀）
material ← catalogs.material_id_to_cc[meta]
runtime  ← cruciblecraft:{material}/{serialized_path}
```

已有前缀（例如 `arrow_gt_wood` / `arrow_gt_plastic`）能对上的，**复用**，
不得再造平行前缀。`units` / `generation_flag` / `tag_directory` 跟现有
`material_prefixes/*.json` 合同；有 GT6 oredict 单位用源，否则
`DESIGN_POLICY` 并记在 remap 行。

`material_id_to_cc` 对不上的 meta：余数 identity，不得猜材料，不得并进
最近的钢。余数必须列出 source_item / meta / 原因。余数为空最好；非空
不自动 BLOCK，但不得 silently drop。

### 3.2 便宜同胞（B，不挡 A）

同一张卡、同一套「能对上材料或已有 catalog 就折，对不上就留下」：

| 对象 | 现态 | 目标 |
| --- | --- | --- |
| 钥匙（铁/金/铜…） | semantic / randomtools 独立物品 | 材料 × `key` 前缀（若干净） |
| 电路线（铜/金/铂…） | technological 独立物品 | 材料 × 已有 `wire` / 专用前缀（若干净） |
| Low Heat Extruder Shape | semantic 再注册一遍 | remap 到已有 `ExtruderShapeCatalog`（34） |

B 不干净就保持 identity，work log 写原因。不得为了收 B 把 A 做成
lossy。画布 16 色、铠甲 12 件只核一眼，不单开范围。

关卡：三件都不干净，identity 留下。钥匙 meta `30000+` 对不上
`material_id_to_cc`。电路线同样是 technological 专用 meta，不能并进
已有 `wire`。Low Heat 是温度档，不能并进 34 件可复用挤出模。

## 4. 实现约束

- **一份 remap 权威。** bath 与 semantic 不得再各写各的
  `runtime_id_for(kind, source, meta)`。`t48_identities.runtime_id_for`
  对 `tool_head` 必须改走前缀物品，或从 emit 删除。
- 新普通波把 `tool_head` 再写成 unique item：编译 fail-closed。
- 物品是 `MaterialItem`，不是 `registerSimpleItem` + 空 Properties。
- 贴图：每种新前缀一张 SOURCE_BACKED GT6 `toolHead*` 底板，走现有
  材料 tint。禁止再写 `minecraft:item/iron_ingot` 占位进 production。
- 创造栏：主页停止 `BathIdentityCatalog` / `SemanticObjectCatalog` 的
  tool_head 倾倒。折回的头跟其它材料形态走。
- `recipe_bulk` emit 是作者源。不要手改几千份 JSON 充数。
- 只读 lock 的 family / `stable_id` 列表；改的是 operand runtime id
  与 generated 正文。
- 被改写波次：重算 generated hash，**重 seal**。不得改
  `complete_family_count` / relation 计数来「看起来更干净」。
- Bath / semantic GameTest 里写死的 `3532` / `4790` 必须改成关卡新计数，
  不得为了绿测把旧 identity 留着。
- 集成客户端仍复用 server epoch。
- 不得把「任意 raw pickaxe head + 油」写成模板。
- 不得丢掉 `stable_id` 或 evidence hash。

1. 缩小到「`material_id_to_cc` 能对上的 tool_head」，余数 identity
   写清；B 项留下；
2. 保持 `BLOCKED`，写清缺的是 remap、前缀门、emit 等价还是硬门；
3. 正式撤回并重签，保留旧卡路径。

不得用开放 tag、拆 Holder、或保留旧 unique item 冒充 READY。
不得把本卡写成 T48 重做或 Item Network Core 已开工。

更新 history index、roadmap、workflow、verification、known-issues 与
