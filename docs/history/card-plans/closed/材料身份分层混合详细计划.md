## 0. 边界

做：

- 公共 16 前缀从 `PREFIX_ITEMS` 挪回 per-material `MaterialItem`，路径 `cruciblecraft:{material}/{form}`。
- 写入精确 `c:{directory}/{material}` 标签。`long_rod` / `bolt` / `screw` / `ring` / `small_gear` 同步 `tag_namespace: c`。
- 长尾库存前缀留在 `PrefixMaterialItem` + `prefix_material`。
- `MaterialLookup` / mill codec：公共前缀解析成 unique Item；长尾仍 rewrite 成组件栈。
- leftover mill/datagen JSON 里的公共前缀 Item + 组件，解析期改成 unique Item；`emit.py` 不再投影公共 16。

不做：

- 哑方块 / 管 / 缆 / hosted ore / 红石线改 BE。
- 流体 / FluidType 展开。
- GTCEu `forge:rods/long` 这类目录别名对齐。
- DataFixer / 旧存档。
- 把公共名单加减成 7 或 17。
- 双注册或兑换壳。

---

## 1. 判定顺序

每个 `(材料, 前缀)` 只命中一次：

1. `formItems()` 外部 Item。
2. 哑方块 / 管 / 缆 / hosted ore：现有 hosted 或按材料独立 Block。
3. 公共 16：独立 Item。
4. 其余库存前缀：共享前缀 Item + 组件。

公共 16：`ingot` `nugget` `dust` `small_dust` `tiny_dust` `plate` `rod` `long_rod` `bolt` `screw` `ring` `gear` `small_gear` `gem` `foil` `fine_wire`。
