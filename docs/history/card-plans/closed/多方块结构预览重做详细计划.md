> 计划 slug：`presentation/multiblock-schema-preview`
> 状态：unique-active。本文件位于 `card-plans/active/`。
> 正式名称：多方块结构预览（按 GTCEu 多方块信息页重做）
> 性质：把 EMI 蓝图页的方块投影换成假世界 + 透视相机的结构预览，并加世界内虚影预览。

## 0. 开场判断

已关的 `presentation/multiblock-emi-projection` 每格调一次
`BlockRenderDispatcher.renderSingleBlock`，没有世界上下文：相邻面不剔除、
没有环境光遮蔽、方块实体不画、正交投影、悬停只找最近的方块中心。那张卡
写了不 mixin、不用滚轮，于是缩放和旋转只能靠一排按钮。试玩反馈：不好看、不实用。

GTCEu（本地 `gtceu_code/GregTech-Modern`）的做法：

- `MultiblockInfoEmiCategory`：每台多方块一张配方，控制器是产物，结构方块
  带数量是输入，不登记分类工作站。
- `MultiblockSchemaInfo` / `MutableSchema`：把结构方块放进一个假 `Level`，
  方块实体一起放。
- ModularUI 的 `SchemaRenderer` 像画世界一样画这个假世界：透视相机，拖动环绕，
  滚轮缩放，射线命中高亮，点方块列候选，层过滤。
- `MultiblockPreviewWidget` 另有「在世界里预览」按钮
  （`PatternPreviewRenderer.showPreview`）。

ModularUI 是 1.20.1 Forge 库，不是本项目依赖，不引入。技术路线照搬，代码自写。

## 1. 做

### 配方口径

沿用已关卡落地时的修正：一种结构 id 一张配方；控制器是产物，也是催化剂；
材料槽按调色板键计数；不登记分类工作站，所以按 R / U 只出这台机器自己一页。
结构从集成服务端的结构快照读，没有快照时把已选资源包按服务端数据打开。

### 假世界

`client/multiblockpreview` 下一个只读 `BlockAndTintGetter`：

- 方块来自 `MultiblockProjectionGrid` 的格子（代表方块规则不变）。
- 亮度恒为满，`getShade` 按原版方向明暗，染色用平原群系。
- `EntityBlock` 按状态建方块实体，只挂在预览里，不进真实世界。
- 控制器用默认状态，面朝北，与 JSON 和校验器的北朝向一致。

### 画面

- 离屏 `RenderTarget`，自带深度，透视投影，画完贴回 EMI 控件。
- `ModelBlockRenderer.tesselateBlock` 传入假世界，相邻面剔除与环境光遮蔽生效；
  方块实体走 `BlockEntityRenderDispatcher`，单个出错就跳过该方块实体。
- 左键拖动：偏航 + 俯仰环绕。滚轮：鼠标在预览框内时缩放，NeoForge
  `ScreenEvent.MouseScrolled.Pre` 截住，EMI 不翻页。不 mixin EMI。
- 射线命中的方块画白框，提示方块名、调色板描述和可用方块列表。
- 层按钮：全部 / 单独一个本地 Y。
- 世界内预览按钮。去掉旧的左右转、俯仰、放大、缩小、朝向按钮。

### 世界内预览

- 在 EMI 页点按钮，准星对着的方块是这张结构的控制器时，以它为原点、按它状态里的
  朝向摆结构（`MultiblockStructureDefinition.worldPosition`）。
- 已满足的格子不画；空着的格子画半透明虚影；放了不对方块的格子画红框。
  判断用 `MultiblockStructureValidator.matches`。
- 30 秒后消失；再点一次关闭。准星没对着控制器时在动作栏提示。
- 只在客户端画，不放方块，不发包。

### 样本

- 焦炉：内部空气不画，相邻耐火砖之间的面被剔除。
- 3×3×3 储罐：墙组一个代表方块；材料槽仍是墙标签。
- 射线：从正面对准控制器所在格，命中控制器；换到单层后只命中该层。
- 世界内预览：朝东的控制器，非原点格子的世界坐标等于
  `definition.worldPosition(core, EAST, offset)`。

## 2. 不做

- 放置方块、自动搭建、从 EMI 点下去放置；建筑权杖保持原样。
- 服务端、网络包、存档。
- `SpecialMultiblockBuilderAdapter` 上的 Java 结构（物质制造机、聚变、物流核心、
  基岩钻、避雷针、范德格雷、大型热交换器、大型动力机、蒸汽涡轮、大型燃气轮机）。
- 结构 codec、校验器、形成逻辑、端口聚合。
- 新结构、新机器、新配方、新贴图。mixin EMI。引入 ModularUI 或别的预览库。
