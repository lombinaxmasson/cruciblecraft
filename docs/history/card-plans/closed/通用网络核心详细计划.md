## 目标

兑现账本「Fluid / Generic Network」里 Generic 两行，并让三件盖板走生存
获得、EMI、创造栏、存档重载和客户端验证：

- `logistics_generic_storage`
- `logistics_generic_transfer`（import / export 是方向数据）

流体基础传输已经是 `player_complete`，本卡不再重做流体三定义。

## 运行时契约

1. 封面 `medium = both`，可贴在物品管 **或** 流体管。未知 Dump id 仍 fail-closed。
2. 物理连通分量仍按宿主管种走图：物品管只连物品管，流体管只连流体管。不是世界广播。
3. 仓储端点 = 同身份 ∩ 已加载 ∩ 同管种分量 ∩ 邻接有物品库存或流体罐。
4. transfer 对邻接物品库存走物品、对邻接流体罐走流体；两种都有则同一 tick 都搬。
5. 物品速率沿 `CoverDefinition` BOTH 上限（默认 8）；流体速率用独立
   `GenericNetworkLimits.DEFAULT_FLUID_RATE`（1000），不把 item rate 当成 mB。
6. 只发现 Generic storage，不把物品/流体 storage 当成 Generic 端点。
7. 无目标不吞；身份活过 reload；load 轴有上界。
