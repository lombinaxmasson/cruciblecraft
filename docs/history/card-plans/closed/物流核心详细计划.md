## 运行时契约

1. **结构（SOURCE_BACKED）**：5×5×5。控制器在任一面中心、朝外；中心沿朝向
   反向偏 2 格。相对中心 `(i,j,k)∈[-2,2]³`：
   - `i²+j²+k² < 4`：27 格内核。允许 versatile / logic / control / storage /
     conversion / 便宜墙。versatile +1 全部 CPU；专用 CPU +4 对应档。
     每种 CPU 至少 1（一颗 versatile 即可）。storage 上限 108。
   - `> 6`：镀锌钢墙，接 EU（不是 44 个 `energy_input` 端口）。
   - 其余：通风单元。控制器占其中一个通风位。
2. **不是加工机**。不挂 RecipeMap，不走 `MultiblockControllerSpec`。
3. **能量（SOURCE_BACKED）**：EU 输入 256–1024/t；大于 1024 炸。操作门槛
   `128 + logic×64×conversion`。闲置每 tick 扣
   `20+logic+control+storage+conversion`。容量
   `128 + logic×256×conversion`。Dump 窗口约每 20 tick。
4. **扫描（SOURCE_DERIVED）**：从壳体 flood 邻接的物品/流体管（有物流盖板的
   管网节点），切比雪夫距离 `≤ 2+control`。不是世界同号广播。
5. **Dump（SOURCE_BACKED）**：盖板不搬东西。Core 在导入/导出/整理之后的最后
   一档，把 Generic **物品**仓储里、过滤集合管不到的剩余物品搬进 Dump 邻接
   容器。`ST.move(..., tFilteredFor, F, F, T, F, 64, 1, 64, 1)`：invert
   过滤，不是虚空。本卡不重做导入/导出/整理（管网六行已做）。
6. **身份（SOURCE_DERIVED）**：同一 flood 图里，Dump 只配对相同 `network_id`
   的 Generic 物品仓储（含双方都是 0）。
7. Dump sidecar 归本卡。底表 `cover_definitions.json` 仍 9 条；
   `registerBuiltin` 仍 8。Dump 目录 18→19。unique-active 期间继续写盖板：
   检索器按 GT6 请求/反相；十档紧凑电动传送带/机械臂/泵走
   `cover_component_tier_definitions.json` sidecar（目录 19→49），
   不是另开一张卡。
8. `ItemNetworkKinds.isForbiddenFrozenKind` 对已登记 Dump 放开；其它未知
   `logistics_*` 仍 fail-closed。

## 本卡做什么 / 不做什么

做：

- Dump 盖板 sidecar、物品、生存配方、EMI、创造栏、中英名（Dump 中文：回收）。
- 控制器 / 镀锌钢墙 / 通风 / 五种处理器方块与 BE。
- 结构判定、墙接电、扫描、Dump 搬运、GameTest。
- 新 capability `logistics/logistics-core`，不得复用
  `portfolio/logistics-cover-net-r0`。
- 继续盖板：管面 BER、检索器请求/反相、十档紧凑电动传送带/机械臂/泵。

不做：

- `CoverLogisticsDisplayCPU*`。
- Core 自己的导入/导出/整理。
- 流体 Dump。
- 改 sealed R0 artifact / `growth_order.json` / census。
- `tools/capabilities/logistics/generic-network/dump/`。
- 给 Core 编造 RecipeMap。
- Batteries 或其它账本切片（本卡占 unique active）。

配方缺 GT6 处理器晶体 / `OD_CIRCUITS[6]` / 焊机四板时，用已有镀锌板、
镀锌机械壳、`programmed_circuit` 和原版宝石做 **DESIGN_POLICY 生存获得**，
几何与 tick 仍 SOURCE_BACKED。贴图从本地 `gregtech6_w` 迁入
`textures/.../gt6_import/`（控制器 / 墙 / 通风 / 五处理器 / 物流九件盖板）。
纪律见 [gt6-art-policy.md](../../../current/gt6-art-policy.md)。
