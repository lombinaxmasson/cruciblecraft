## 0. 决策

物流封面网络 R0 已关闭为 `LOGISTICS_COVER_NET_R0_READY`。可行性是
`requires_new_runtime`，`allows_core_child = false`。下一张不得签物流
core，也不得按 sealed growth-order 的第二轨机械签发
`portfolio/count-ceiling-kind-envelope`。也不把
`post_generator/combinatorial-family-intake` 提前：四条 combinatorial 仍缺
family-atomic 枚举、玩家路径、执行信封和 load 证据。

进入 growth-order 第三轨
`portfolio/existing-mechanism-bounded-domains` 的第二个命名义务，但整轨
（物流封面网 + T13c 排除表收回）不是一张卡。先签最小可审查切片：

```text
portfolio/t13c-exclusion-reclaim-r0
```

它只回答：capability map 点名的五类 T13c exclusion（129 source sites /
471 expanded）能否由**已有** CC 机制作有界扩展承载，还是必须另开 runtime
或交给独立 portfolio。R0 READY 不等于 MTE 实现，也不等于全表 763/1,701
收回，更不在 topology 预分配实现 child。

## 5. 收回契约与可行性

`reclaim_contract.json` 只冻结后续实现卡必须回答的问题，不实现它：

```text
disposition_policy  per-category implemented | planned | deferred | out_of_scope
player_acquisition  如何进入生存/创造路径
energy_coupling     batteries / reactors 与 T18 已选转换链的边界
panel_semantics     6 sites → 348 expanded 的 multiplicity 规则
sensor_semantics    检测、红石输出、是否加入任何网络
portal_semantics    链接、维度旅行、存档
reactor_semantics   part vs controller；不得本卡实现
load                玩家获取 / 存档 / 服务器行为分轴测量
fail_closed         未知 variant 不得 silent no-op
```

`feasibility.json` **按类别**取值：

```text
bounded_extension     该类可由具名现有 CC runtime 有界扩展承载
requires_new_runtime  必须另开 runtime，不能假装是已有栈的又一批条目
defer_to_portfolio    合法去向是另一个已命名 portfolio（仅 Reactors → nuclear）
blocked               缺 dump、缺 schema 或缺测量计划，不能对该类给出结论
```

只有 `bounded_extension` 才允许另签该类 implementation child。
`requires_new_runtime`、`defer_to_portfolio` 或 `blocked` 不得在本卡
topology 预分配实现后继。R0 卡本身仍可 `T13C_EXCLUSION_RECLAIM_R0_READY`：
那只证明分母和逐类 verdict current，不等于实现 READY。

预期（预读，实施时必须用证据重放，不得手填）：五类目前都是
`cc_mechanism = none`。Panels / Sensors / Portals / Batteries 很大概率
`requires_new_runtime`；Reactors 必须 `defer_to_portfolio` 且
`nuclear_started = false`。

## 8. 撤回

实施中发现阻塞时只有三种合法结果：

1. 在本卡内补齐验收证据；
2. 保持 `BLOCKED`，写清缺的是 dump、schema 还是测量计划；
3. 正式撤回并重签，保留旧 denominator hash。

不得用「先写一点 Java MTE 再补契约」绕过 R0。不得把 129/471 对照写成
GT6 排除表完成，也不得把 T18 已选能源链或 T19 相邻封面写成已经覆盖
Panels / Sensors / Portals / Batteries / Reactors。

关闭时：本计划移到 `card-plans/closed/`，补 stage archive 与 work log
收口；更新 history index、roadmap、workflow 与 verification；不重写已
sealed 的 growth-order JSON；不自动创建 Git commit。
