## 运行时契约（SOURCE_BACKED）

`TileEntityBase11Bidirectional`：

1. 正面默认是高压输入；其余五面低压输出。`isInput` / `isOutput` 随
   `mReversed` 对调。
2. 正向：收 `V[i+1]`，发 `V[i]`，倍率 4。反向：收低压、发高压（revert
   converter 倍率 1）。切换时清空内部储能，避免过充。
3. GT6 用 **monkey wrench** 翻转；放大镜读 `Normal` / `Reversed`。CC
   使用独立的 `material_monkey_wrench`（活动扳手），普通
   `material_wrench` 不可翻转变压器。
4. 只接受 / 只发出 EU。不是 LU，不是 RU/KU/HU。
5. 九台共用一套 `transformer_electric` 贴图；材质色走
   `Electric_T[i]`。overlay / overlay_active / overlay_blinking 是这台机器
   自己的活动层，**不是**加工机 `overlay_active` ↔ `LIT` 那张后继卡。

## 配方（必须按 GT6 逐格，禁止占位假装完成）

GT6：`"WIW", "XMx", "WIW"`。`M` = `OP.casingMachine`（该档
`Electric_T[i]`）；`W` = `OP.wireGt01`；`X` = `OP.wireGt04`；`I` =
`OP.plateDouble` 铁；小写 `x` 为空。T0–T2 导线 `ANY.Cu`；T3+ 退火铜。

允许的翻译（同一对象，不是替身）：`wireGt01` → `wire`；`wireGt04` →
`quadruple_wire`；`casingMachine` → 该材料的机壳形态（与板、杆同类的材料形态，
不是变压器专用、不是 EU/HU 专用）；`plateDouble` → `double_plate`；
`MT.Os` → `osmium_elemental`。`ANY.Cu` 只能落到铜系成员，不得换成铁或其它
金属。GT6 机壳由板+长杆做出；不是每种材料的壳都会被某台机器配方用到。
CC 现在只有硬编码的一小份机壳物品，本卡不新造壳、不用现有壳顶替。缺该档
`Electric_T` 机壳时该档配方不进游戏。

别的板、棒、电缆、原版铁锭或 `programmed_circuit` 顶格；不得发明几何；
不得只因为创造栏能拿到或「用已有材料也能拼出来」就写生存配方并晋级
