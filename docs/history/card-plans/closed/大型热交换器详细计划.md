## 1. 和 GT6 对齐的部分

- 底圈 8×18024 绑成 `ONLY_ITEM_FLUID_ENERGY_IN`。热流体进入主机输入罐；这些面不能抽出废液。主机没有物品库存，也不接收能量，所以舱口的活表面是流体输入。
- 顶心 18024 与 8 个 18101 是 `NOTHING`，不接流体。
- 热量从每个热传递器上方的方块注入，包大小 1，速率 16384 HU。
- 废液自动推到主机正下方，主机底面可以抽出废液。
- 不足 8 HU 的余量在本 tick 丢掉，和源码 `mEnergy < 8` 一致。

## 2. 明确留下的差别

单方块热交换器已经把无效燃料留在罐里并标 `invalid_fuel`。17197 源码会立刻清空对不上的输入。这张卡沿用单方块合同，不把玩家刚灌进去的流体删掉。
