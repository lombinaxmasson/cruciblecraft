## 0. 开场判断

打磨机之后，MTE 加工机身份卡里剩下的新 Basic Machine RecipeMap 只有熔炉。
`Heat_T[1..4]`：钢 / 殷钢 / 钛 / 碳化钨。能量面是底面 HU，不是动能顶面。
获得格 `"wMh","BCB"`：单层 `OP.casingMachine`、铜双板、原版砖块。
dump 是空的 `EMPTY_PINNED_MAP`；不得把空 dump 编成 compact family，也不得用
GT 粉→锭顶原版烧炼。工业熔炉查原版烧炼表，不替换原版熔炉方块。

R0 catalog 只点了 20004；20001–20003 仍实现四档主机，不改 R0 disposition。
