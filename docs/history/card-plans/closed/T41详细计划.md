## 3. 已知范围和风险

| 分类 | Families | Relations | 约束 |
| --- | ---: | ---: | --- |
| T37 calibration already live | 50 | 50 | `#0002–#0051` 不进本波 lock |
| singleton exact in lock | 292 | 292 | 全部 authored；其中 50 条 leftover-vanilla 与 T37 运行时身份碰撞 |
| combinatorial deferred | 2 | 1,239 | `#0000`/`#0001` BLOCKED |

T37 `#0002` 的 GT6 源是 Rubberwood plank，生成时按设计策略折成 `minecraft:oak_planks`
+ circuit → oak button。T41 `#0290` 的源是真正的 vanilla oak，诚实映射也是同一 generated
core。Admission 当时只比 GT6 family ID，所以 leftover-vanilla `#0290–#0339` 进了 lock。
闭卡记账把这 50 条计为 **T37 已表达**，不把它们算成 292 条独立 live 身份。

其余 GT 木（Maple / Dead / Rotten / Fireproof / Rubberwood 等）继续走
`cruciblecraft:gt_wood/{slug}`（含 `cruciblecraft:fireproof=1`），不折到 leftover vanilla。
datapack 文件名不得含 `=`。

同 target map 上 T37 与 T41 多 group 必须原子 reload。Publication/load 仍报告 292 authored
compact；live map 在 reload 时按 **logical input identity**（stack + count + action + fluids）
丢掉已由 T37 表达的 50 条。不得用 Ingredient `toString` 当 drop key。
