## 0. 开场判断

缺口账本第 8 项是「热力机器逐台闭环」：先热交换器，再按来源依赖分别做蒸汽涡轮和冷却器。
一张卡同时做 HU / RU / CU、单体与大型多方块、转子耐久，会再次把裂变收尾做成核电大卡。

```text
本卡（热交换器第一切片）
  8 个单体 Heat Exchanger 身份
  + FM.Hot 输入 → HU 输出
  + 来源 shaped 获得
  + 来源贴图

后续卡（点名，不进本分母）
  蒸汽涡轮 STEAM → RU（约 1512+）
  电/通量冷却器 EU/RF → CU+HU（10161+ / 11161+）
  大型热交换器 17197
```

### 1.1 获得格（实施第一天必须写成 D0）

普通四台（`PCP / OwO / PMP`）：

| 键 | GT6 | 已知风险 |
| --- | --- | --- |
| `M` | `OP.casingMachine(aMat)` | Invar / tungstensteel / tantalum_hafnium_carbide / ANY.W |
| `O` | `OP.pipeSmall(ANY.Cu)` | 铜族小管，不得换成无关金属 |
| `P` | `OP.plate(MT.Pb)` | 铅板已有 |
| `C` | `OP.plateDouble(ANY.Cu)` 或 `MT.AnnealedCopper` | 9103 用 ANY.Cu；其余三台用 AnnealedCopper |
| `w` | 扳手催化剂 | 已有 `material_wrench` |

致密四台：

| 键 | GT6 | 已知风险 |
| --- | --- | --- |
| `M` | `OP.casingMachineQuadruple(aMat)` | CC **没有** `machine_casing_quadruple` 活前缀；不得用 `machine_casing_dense` 顶 |
| `O` | `OP.pipeLarge(ANY.Cu)` | 铜族大管 |
| `P` | `OP.plateQuadruple(MT.Pb)` | 铅四层板 |
| `C` | `OP.plateDense(ANY.Cu)` / AnnealedCopper | 致密板 |

D0 规则与盖革相同：缺真零件 = 该行 `explicitly_blocked`，不写替身配方。
若致密四台只缺 `casingMachineQuadruple`，允许像铝 `capcellcon` 那样 **只给本卡材料** 加真前缀（来源 extruder/获得也必须 exact）。不得把致密外壳、双层外壳或铅板拿来顶四层外壳。

`ANY.W` 落到钨族成员，不得落到无关金属。`Ta4HfC5` → 已有 `tantalum_hafnium_carbide`。

### 1.2 运行时合同

- 输入是已关闭热流体卡的 `FM.Hot` 身份，不是把热流体映射回冷流体。
- 输出是 HU，不是 RU / EU / CU，也不是 Kelvin。
- 效率：钨钢两台 90%（`NBT_EFFICIENCY 9000`），其余 100%。
- 结构是单体方块，不是 17197 大型热交换器。
- 贴图从本地 `gregtech6_w` 拷贝，禁止用锅炉 / 转换机 / 套管贴图占位。

## 2. 明确不接管

- 蒸汽涡轮（`MultiTileEntityTurbineSteam` 1512+，STEAM → RU）
- 电冷却器 / 通量冷却器（`MultiTileEntityCoolerElectric` 10161+，`MultiTileEntityCoolerFlux` 11161+）
- 大型热交换器 `17197` / `MultiTileEntityLargeHeatExchanger`
- 堆芯、防护服、盖革、Jade、Kelvin、世界爆炸
- 聚变 / 等离子
- 全量 `OP.capcellcon` 族或全量 `casingMachineQuadruple` 族（只允许本卡获得格需要的材料实例）

## 3. 实施顺序

1. D0 写成 8 行获得矩阵：每格 GT6 对象 → CC 身份，或 `explicitly_blocked`。
2. 只对 D0 判定需要的缺失真前缀（很可能是四层外壳）做 in-scope 添加；否则保持 blocked。
3. 注册 8 个（或 D0 放行的子集）单体身份、HU 输出、`FM.Hot` 消费。
4. 来源贴图 + 配方 JSON。缺格不发明。
5. GameTest：热流体进、HU 出、效率、存档。
6. 实施开始时才创建 wave / capability；`unique_active_wave` 到那时才非空。关闭时回到 `null`。

日常验证：`python tools/verify.py dev`。`promotion` / `--client` 只在
`runtime_ready → player_complete` 时强制。

---

## 4. BLOCKED / 撤回

必须保持 blocked：

- 用 `machine_casing_dense` / 双层外壳 / 铅板顶 `casingMachineQuadruple`
- 用 Invar 顶 ANY.W 或 Ta4HfC5
- 把 HU 乘常数当成 Kelvin
- 注册涡轮、冷却器、17197、聚变 Jade
- 为了「能合成」把热流体改回蒸汽或冷水

撤回时保留 D0 矩阵；不要删已确认的热交换器身份。
