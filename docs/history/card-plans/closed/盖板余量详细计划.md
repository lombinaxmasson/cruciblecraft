## 宿主

今日盖板只在流体管 / 物品管。本卡把 `PipeCoverSet` 接到
`ProcessingMachineBlockEntity`。控制器写入 `coverEnabled`，折进
`processingAllowed()`。盖板在停机时仍 tick。拆方块掉盖板。

红石出：弱信号 `getSignal`，强信号仅 cutter 位时 `getDirectSignal`。
查询方向与 Display CPU 相同：cover 面 = `queryDirection.getOpposite()`。

## 行为合同（按官方 `gregapi/cover/covers` 复核）

- 共同控制器宿主是 `ITileEntitySwitchableOnOff`；拆除控制器恢复 ON。
  `controller_auto` 放置还必须 `canTick` + `RunningPossible`，状态为
  `RunningPossible || RunningActively`。
- `controller_redstone` 的状态是 incoming 与 invert 位不同；
  `controller_auto_redstone` 为
  `RunningActively && !RunningSuccessfully` 或 incoming 与 invert 位不同。
  螺丝刀只翻 invert 位。
- 五档 `controller_auto_timer` 在 `onTickPre` 中按
  `RunningActively || timer % period >= period - 10` 驱动机器，周期为
  `1200 / 6000 / 12000 / 24000 / 36000`；其普通状态返回 true。
- `controller_display` 不在 `onTickPre` 驱动机器；`onTickPost` 写入
  possible/passive/active/on 四组状态位，右键 hotspot 切换机器，凿子切换两套皮肤。
- `controller_covers` 不驱动机器，只以 incoming == invert 更新
  `CoverData.setStopped`，从而停用同宿主的其它盖板；`vent` 尊重 stopped。
- `detector_*` 要求对应 `ITileEntityRunning*` 且 `canTick`。默认弱输出为
  0/15；cutter 位才输出强信号，螺丝刀位反转条件。
- `scale_energy` 要求 `ITileEntityEnergyDataCapacitor`，`scale_progress` 要求
  `ITileEntityProgress`；值为 0–15 的满度刻度，螺丝刀反转输出方向。
  `display_energy` 同能源宿主但写 0–10 视觉值，不输出红石。
- `selector_redstone` / `selector_tag` / `selector_button_panel` 要求
  `ITileEntitySwitchableMode`。红石选择器取 incoming 的 0–15；标签选择器固定
  mode；按钮板为 4×4 mode，螺丝刀切换按下后复位/保持。
- `redstone_emitter` 的视觉值为 0–15，右键调节；cutter 位决定弱/强输出。
  conductor IN 只作标记，OUT 在方块更新时取所有 IN 面 incoming 的最大值并弱输出。
- `vent` 要求 `canTick` + `IFluidHandler`，在
  `SERVER_TIME % 360 == 30 + 60 * side` 且相邻方块可收集空气时，按维度/生物群系
  注入 256000 air / Nether air / End air，并走宿主 fluid handler。
- `redstone_torch` / `redstone_repeater` 只接受
  `MultiTileEntityWireRedstoneInsulated`；torch 条件为红石大于 0，repeater 条件为
  红石不大于 0。当前 CC 红石线未落地，因此两者定义保留但机器/管道安装必须拒绝。

## 配方（无顶替）

空白盖板：`Sh `/`Pd `，P=aluminium/plate，S=aluminium/screw，
h=smithing_hammer，d=material_screwdriver（催化剂）。
其余网格按 MultiItemTechnological 142–174。
`OD_CIRCUITS[1..5]` → circuit_basic/good/advanced/elite/circuit_master。
`CABLES_01[1]` tin/cable，`[2]` copper/cable。`WIRES_01[1]` tin/wire。
Lumium `wireGt01` → lumium/wire。`ANY.Iron` → iron/rod、iron/rotor。
`MT.RedAlloy` → red_alloy/wire。缺件则整条不写，不顶替。

逐项网格（字符布局来自官方 `MultiItemTechnological.java`）：

- `controller_display`：`LLB/CQW`；L=lumium wire，B=lever，C=circuit_basic，
  Q=blank，W=tin cable。
- `controller_auto`：`BW/CQ`；B=lever，C=circuit_basic，W=tin cable，Q=blank。
- `display_energy`：`CLB/WQW`；L=lumium wire，B=tin wire，
  C=circuit_basic，W=tin cable，Q=blank。
- `controller_redstone`：`BW/CQ`；B=vanilla redstone torch，
  C=circuit_basic，W=tin cable，Q=blank。
- `controller_auto_redstone`：`BW/CQ`；B=lever，C=circuit_good，
  W=copper cable，Q=blank。
- `selector_redstone`：` C /WQX/ B `；C=circuit_basic，W=copper cable，
  B=comparator，X=programmed circuit（selector mode 1）。
- 五档 timer：分别为 `BWd/CQ `、`BW /CQd`、`BW /CQ /  d`、
  `BW/CQ/ d`、`BW/CQ/d `；B=vanilla repeater，d=material screwdriver，
  W=tin cable，Q=blank，C 依次为 circuit_master/elite/advanced/good/basic。
- `scale_energy`：`WQW/BCB`；B=tin wire，C=circuit_good，W=tin cable，Q=blank。
- `detector_running_possible`：同 `WQW/BCB`，B=comparator。
- `detector_running_passively`：同上，B=vanilla repeater。
- `detector_running_actively`：`WQW/BCX`；B=comparator，X=vanilla repeater。
- `scale_progress`：同 `WQW/BCB`，B=brass small gear。
- `detector_running_successfully`：`WQW/BCX`；B=button，X=vanilla redstone torch。
- `redstone_emitter`：`BQB/WXW`；B=button，W=tin cable，X=comparator，Q=blank。
- `vent`：`RRR/RXR/RRR`；R=iron rod，X=iron rotor。
- `controller_covers`：`BW/CQ`；B=comparator，C=circuit_good，W=tin cable，Q=blank。
- `selector_button_panel`：`BXB/BQB/BCB`；B=button，C=circuit_basic，
  X=programmed circuit，Q=blank。
- `redstone_conductor_in` / `_out`：分别为 `R/Q` 与 `Q/R`；R=red alloy wire，
  Q=blank，并保留官方 shapeless 互转。
- `selector_tag` 不新增物品或伪造网格；由已有 programmed circuit 的配置值映射
  到 GT6 的固定 mode。火把/中继器仅是原版物品的宿主拒装路径，不生成机器盖板替代配方。
