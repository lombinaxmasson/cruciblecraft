范围：

- GT6 `MultiTileEntityImplosionCompressor` 17110、`RM.ImplosionCompressor`
  与 3×3×3 / 18023 / `ITEM_FLUID_ENERGY` 结构。
- `EnergyType.TIME`、1/1/16 TU、并行 64、无自动输入、底部自动输出与
  工艺开始爆炸音效。
- 主机的真实 `CPC/PAP/RMR` 合成；`A=IL.ROBOT_ARMS[2]` 是 `PAP` 中的真实
  机器人臂配料。
- GT6 1072 条源行；当前可解析行发布，其余真实材料形态保留 blocked
  overflow，不使用 stand-in。
- GT6 原图、GUI、EMI、GameTest、Python landing check 与 capability ledger。

安全边界：

- 不注册第二个 18023 墙身份。
- 不把单块 `compressor` RecipeMap 或 `programmed_circuit` 当作聚爆压缩机
  的替代实现。
- 不通过 ItemEntity worldgen 补获得性。
