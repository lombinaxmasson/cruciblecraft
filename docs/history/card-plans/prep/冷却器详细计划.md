> 计划 slug：`energy/cooler`
> capability_slug         = energy/cooler
> unique_active_wave      = null
> 状态：prep（不占落地锁） / frozen
> 正式名称：电力 / 通量冷却器
> 性质：缺口账本第 8 项的冷却器卡。对照 GT6 `MultiTileEntityCoolerElectric`
> 10161–10165 与 `MultiTileEntityCoolerFlux` 11161–11165。
> 热交换器、蒸汽涡轮、大型热交换器 17197 不在本卡。

## 0. 开场判断

```text
本卡
  5 台热电冷却器  EU → CU(前) + HU(后)   10161–10165
  5 台热通量冷却器 RF/FE → CU(前) + HU(后) 11161–11165
  + NBT_WASTE_ENERGY
  + 来源 shaped 获得
  + 来源贴图

不做
  热交换器 / 蒸汽涡轮 / 17197
  EnergyType.RF 新身份
  用 EU 顶通量输入
```

通量冷却器的 GT6 输入是 `TD.Energy.RF`。CC 没有 `EnergyType.RF`。本卡把
RF 数量 1:1 译成 NeoForge FE（`IEnergyStorage`），不发明 RF 能量种，也不把
通量机改成收 EU。


来源：`Loader_MultiTileEntities.java` 984–996。
`NBT_ENERGY_ACCEPTED` EU 或 RF，`NBT_ENERGY_EMITTED` CU，
`NBT_ENERGY_EMITTED_2` HU，`NBT_WASTE_ENERGY` true。
`doTwinType`：前脸 CU、后脸 HU，输入面是非轴向四面。
电力冷却器有 `ITileEntitySwitchableMode`（螺丝刀 0–15）。

`Electric_T[1]` 是镀锌钢（LV），不是锡合金。`Flux_T[1]` 是铅，不是锡。

### 1.1 获得格

电力：`WPw / CMC / xPW`

| 键 | GT6 | CC |
| --- | --- | --- |
| `M` | `OP.casingMachine(Electric_T[n])` | 对应材料 `machine_casing` |
| `W` | `CABLES_01[n]` | 锡 / 铜族 / 金 / 铝 / 铂 `cable` |
| `P` | Si 板层随阶 | `silicon` plate…quintuple_plate |
| `C` | ANY.Cu 板层随阶 | `copper` 同层板 |
| `w` `x` | 扳手 / 剪线钳催化剂 | GT6 CR `w`/`x` |

通量：`PSP / PMP / PSP`，`M` 是对应电力冷却器，`P` 板、`S` 长杆为 Flux_T。

D0 十行均为 source-exact。ANY.Cu 落到铜。缺格不发明替身。

### 1.2 运行时

- 电力：EU 包电压，超过 `2×NBT_INPUT` 过载清缓冲。螺丝刀切 mode 0–15。
- 通量：FE 按数量灌入同一缓冲，不做 RF 电压过载。通量机没有 SwitchableMode。
- 每 tick `tOutput = stored * NBT_OUTPUT / NBT_INPUT`；低于 `NBT_OUTPUT/2` 不发射；
  然后按 `NBT_WASTE_ENERGY` 扣掉 `units(2×INPUT, 16, 16-mode)`。
- CU `size=1` 向前推，HU `size=1` 向后推。
- 贴图从 `machines/cooler/cryo_electric` 与 `cryo_flux` 拷贝，禁止占位。
