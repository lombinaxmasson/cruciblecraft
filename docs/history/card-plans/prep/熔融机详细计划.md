## 1.1 获得格（D0）

网格 `"wUh","PMP","BCB"`。`w` 扳手、`h` 锤。

| 键 | GT6 | CC（`gt6_resolve` 2026-09-09） |
| --- | --- | --- |
| `M` | `OP.casingMachine(ANY.Iron)` | 铁/钢族 `/machine_casing` 已有 registered 成员（iron / steel 等）。enori 外壳未登记，不得选它 |
| `P` | `OP.pipeMedium(aMat)` | 铁族中管：`iron/fluid_pipe` 与 `steel/fluid_pipe` registered。其它铁族成员中管多为 missing_form，落地选已登记成员 |
| `C` | `OP.plateDouble(ANY.Cu)` | copper / annealed_copper `/double_plate` registered |
| `B` | `Blocks.brick_block` | 原版砖块（1.21 `minecraft:bricks`）。这是原版身份，不是用其它 CC 方块顶 |
| `U` | `aRegistry.getItem(1005)` 陶瓷冶炼坩埚 | 生坯 `raw_ceramic_crucible` **不是**这格。烧制配方产出 `cruciblecraft:crucible`（`machine_material=ceramic`），即 CC 对 1005 的坩埚方块物品。不得用熔炼炉或其它机器顶 |

缺格不发明。当前材料格可 source-exact（铁族已登记成员 + 铜双板 + 原版砖 + 陶瓷坩埚方块）。
不得用未烧生坯顶 `U`。
