# 微型燃气涡轮详细计划

> capability slug: `energy/small-gas-turbine`
> wave slug: `energy/small-gas-turbine`
> 状态：prep。用户当场改开 Hammer / Squeezer / Laser，本卡让出 unique-active。
> 工作类型：把 kTFRUAddon 单方块 Small Gas Turbine 作为 CC **DESIGN_POLICY**
> 扩展移植到现有 `FuelGenerator` 宿主；燃料图是 GT6 `FM.Gas`
> （`gt.recipe.fuels.gas`），不是已有的 `fuels_gas`（那是 `FM.Burn` 燃烧室）。
> 用户当场确认 DESIGN_POLICY（2026-09-19）：7 档全开 + 导入 9 条 `FM.Gas`。

```
capability_slug         = energy/small-gas-turbine
unique_active_wave      = null
lane                    = prep
```

这不是 GT6 原版机器。GT6 燃气涡轮是大型多方块
`MultiTileEntityLargeTurbineGas`（HU 入、`FM.Gas`、RU 出）。kTFRUAddon
`MultiTileEntityGasMotor` 只是 `MultiTileEntityMotorLiquid` 的四行子类，
把 `NBT_FUELMAP` 改成 `FM.Gas`。CC 不得把它写成 GT6 loader 行。

## 范围

来源：`ktfruaddon/kTFRUAddon` `tileEntityInit0.initEnergyTiles` 10000–10006，
效率 3500 bps，正面 RU、背面排气，配方网格 `PLP / SMS / GOC`。

| id | 材料 | RU 包 |
| --- | --- | ---: |
| `bronze_small_gas_turbine` | bronze | 16 |
| `steel_small_gas_turbine` | steel | 32 |
| `invar_small_gas_turbine` | invar | 64 |
| `titanium_small_gas_turbine` | titanium | 128 |
| `chromium_small_gas_turbine` | chromium | 256 |
| `tungstensteel_small_gas_turbine` | tungstensteel | 372 |
| `iridium_small_gas_turbine` | iridium | 768 |

`source_id` 用 110000–110006（kTFRUAddon 10000–10006 加偏移），避免撞上
GT6 电加热器 10001–10005。转换机目录因此变成 179 GT6 行 + 7 行 DESIGN_POLICY。

燃料图 `cruciblecraft:fuels_gas_turbine` ← dump `gt.recipe.fuels.gas` 9 行：
hydrogen / deuterium / tritium / methane / natural_gas / propane / butane /
ethylene / propylene。禁止指到现有 `fuels_gas`。

## 做 / 不做

做：

1. 新 kind `small_gas_turbine`，runtime 共用 `FuelGeneratorBlock`。
2. 导入 9 条 `FM.Gas`；MotorLiquid 只保留第一路排气（水），丢掉第二路 CO2。
3. 贴图复用 `fuel_engine`（kTFRUAddon 未设 `NBT_TEXTURE`）。
4. EMI / 中英名 / 创造栏能源页（转换机目录自动进栏）。
5. GameTest：七档数值、甲烷→RU、九条燃料图。

不做：GT6 大型燃气涡轮、飞轮、手动马达、改公共 16 前缀、stand-in 配料。
润滑剂沿用转换机已有的蜂蜜瓶映射，不新造润滑油。缺形态的档配方保持跳过，
不把 `blocked.md` 当开形态队列。

## 验收

- 本卡不占 unique-active；计划在 `card-plans/prep/`。
- `python tools/build_capability_ledger.py --check` 与
  `python tools/build_project_status.py --check` 绿。
- 青铜机能烧甲烷出 RU；`fuels_engine` 柴油不得当本机燃料。
- 关闭仍走 `python tools/close_capability.py --capability energy/small-gas-turbine --change-class major`，
  本卡未关。
